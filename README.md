# quick_tools

A smart Python toolset for manipulating and filtering lists.

## What this Package Does

- Removes specific values from a list completely.

- Removes duplicate items while keeping the original order.

- Selects a random element safely from any list.

- Converts two lists (keys and values) into a dictionary.

- Checks if text contains only alphanumeric characters.

- Filters or extracts elements from a list based on custom conditions like greater than, less than, or equal.
